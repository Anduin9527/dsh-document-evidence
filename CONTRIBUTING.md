# Contributing

Report the dsh, Node, Python and OS versions with a minimal synthetic PDF reproduction. Do not attach private documents or credentials. Run the tests and release checks listed in README.en.md before proposing changes. Keep source citations and incomplete-coverage signals intact; a smaller prompt is not an improvement if it drops new evidence.

Contributions are accepted under the project AGPL-3.0-only license. No model API key is needed for local tests.

## Publishing

See [the publishing guide](docs/publishing.md) for the one-time npm trust setup and tag-based releases.
